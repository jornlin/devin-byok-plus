📖 使用教程 必读
快速开始
  1. 第一步：配置连接 - 在「⚙️ 配置连接」页点方案列表里的方案（或「＋ 新建」）打开编辑器，为 BYOK #1 填写 Base URL 与 API Key，点「加载模型」并选择模型；也可点「导入 Claude 配置」/「导入 GPT 配置」直接读取本地 ~/.claude、~/.codex 的现有配置。BYOK #2 至 #4 为可选槽位，可指向不同厂商。
  2. 第二步：安装补丁 - 切换到「🔧 系统补丁」页，点「安装补丁」把代理地址注入 Devin Desktop，完成后重载窗口。
  3. 第三步：启动代理 - 切换到「🚀 控制状态」页，点「一键启动」。三步的完成状态见该页顶部的流程指示器。
  4. 第四步：在 Devin 里选模型 - 打开模型下拉框，选择你配置的模型（默认「替换」模式下显示的是真实模型名，如 Claude Opus 4.8）。
配置方案
  • 一整套配置（4 个槽位 + 高级路由 + 提示词）存为一个方案，可建多个方案随时切换。
  • 编辑器打开时，改动会自动保存（约 650ms 防抖）；点「💾 应用到方案」可立即写入。
  • 方案列表里点「启 用」切换当前生效的方案；标「未配齐」表示 BYOK #1/#2 还缺 Key 或模型。
  • 列表上的 ↑ 是单次输出上限，⊞ 是 Devin 显示的上下文额度。
让 BYOK 模型出现在下拉框
  • Devin 服务端已不再下发 BYOK 条目，代理会改写模型清单把槽位放回去。在「🚀 控制状态 → 模型接管」调整，即时生效，重新打开 Devin 的模型下拉框即可。
  • 替换（默认）只显示 BYOK 槽位并展示干净的模型名；注入保留官方模型并追加 BYOK 槽位（Pro 账号可继续用官方额度）；关闭不接管。
  • 默认使用 Cascade（默认开启）：新建会话默认选中的「Devin Local」走独立 CLI，不经过本插件，模型列表里没有 BYOK 条目。该开关改的是 Devin 自身设置，需重载窗口生效。
常见问题
  • 下拉框里没有配好的模型：确认代理已启动、补丁已安装且重载过窗口；再检查「模型列表模式」不是「关闭」。
  • 生成中途截断、工具参数 JSON 不完整：大概率是「高级路由配置 → 最大 Token」超过了模型经网关的实际输出上限，调回 32K 试试。它是单次输出上限，与「上下文窗口」是两件事（后者仅影响 Devin 界面显示）。
  • 聊天没有走代理：重新安装补丁并重载窗口。Devin 升级会覆盖补丁，属预期行为。
  • 模型列表加载失败：检查 Base URL、API Key、余额与网络，并看「控制状态 → 代理日志」的报错。
  • GPT 报 /v1/responses 相关错误：在「高级路由配置」把 OpenAI API 路径改为 /v1/chat/completions。
每个槽位可独立设置网关、Key、模型、API 协议（自动 / anthropic / openai / gemini）与思考强度；思考强度选项会按厂商自动变化（Claude adaptive、GPT reasoning.effort、Gemini thinking_level），GPT 另有 Processing Tier，gpt-5.6* 还可设推理模式。
